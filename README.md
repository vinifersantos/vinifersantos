## 🛸 Sobre mim

Sou um desenvolvedor em formação com experiência prática em **vendas, varejo, indicadores comerciais e criação de produtos**.

Minha direção é clara: transformar problemas operacionais em sistemas simples, mensuráveis e úteis. Por isso, estudo programação sem separar tecnologia de negócio — o código precisa melhorar uma operação, apoiar uma decisão ou criar uma nova fonte de valor.

Hoje concentro meus projetos em:

- **Sistemas SaaS, CRMs e ferramentas internas**
- **Dashboards comerciais, financeiros e operacionais**
- **Automação de processos e organização de dados**
- **Produtos digitais com experiência de uso clara**
- **Aplicações com autenticação, banco de dados e controle de acesso**

> **O código é a nave. O destino é resolver problemas reais.**

## 🧠 Princípios de desenvolvimento

- Clareza antes de complexidade.
- Sistema bonito é bom; sistema útil é obrigatório.
- Regra de negócio deve ser compreendida antes de ser automatizada.
- Banco de dados, autenticação, segurança e deploy começam no planejamento.
- A interface deve parecer simples, mesmo quando o sistema é complexo.
- Documentar o raciocínio faz parte de aprender a programar.
- Código limpo é respeito por quem dará manutenção — inclusive meu eu do futuro.
